# LeadScout Email Engine

A simple email finder and verifier project.

## Goals

* Find public emails from websites
* Extract emails from contact and about pages
* Verify email format
* Check MX records
* Score lead quality

## Version 0.1

Input:

* Website URL

Output:

* Emails found on the website

## Future Versions

* Contact page crawler
* Email verification
* Lead scoring
* CSV export
